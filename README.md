# KoMaP 2026 AI 경진대회 — 알루미늄 합금 미세조직 상 분할

> 소규모 현미경 이미지(학습 70장)로 4개 상(phase)을 픽셀 단위로 분할하는 U-Net 모델 개발
> 처음으로 직접 모델을 학습시켜 본 프로젝트 (2026.10)

## 1. 대회 개요
| 항목 | 내용 |
|---|---|
| 대회 | 2026 KoMaP AI 경진대회 (주최: 산업통상부·한국산업기술진흥원 / 주관: ETRI·한국재료연구원) |
| 과제 | 고탄성 주조용 알루미늄 합금 광학현미경(OM) 이미지의 상 분할 |

| 평가 | 이미지별 4클래스 mIoU → 평가 이미지 평균 (참고 기준 성능 약 75%) |
| 일정 | 제출 마감 10/15 · 예선 발표 10/22 · 본선 발표 10/29 (킨텍스) |

- 수업 실습 수준을 넘어 데이터 분석부터 학습·평가·제출까지 직접 해보고 싶었음

## 3. 데이터 분석
- **클래스 불균형**: Al 58% · Al3Ni 25% · 초정 Si 9.6% · 공정 Si 7.1% (학습+검증 픽셀 기준)
- **해상도 제각각**: 675×480 ~ 1440×1024, 5종
- **조명·대비 편차**: 같은 상(초정 Si)이 이미지에 따라 회색 또는 검정으로 보임
- **미세 구조**: 공정 Si가 수 픽셀 폭의 가는 바늘 형태 → 축소하면 정보 손실
- 이미지는 사실상 흑백(R=G=B)이고, 마스크는 정확히 4색으로 구성됨

## 4. 접근 방법 (선택과 이유)
| 선택 | 이유 |
|---|---|
| U-Net + ImageNet 사전학습 ResNet34 | 데이터 70장으로는 처음부터 학습하기 어려워서 사전학습 특징을 활용함 |
| 원본 해상도에서 512×512 랜덤 크롭 | 공정 Si 같은 가는 구조를 보존하고, 적은 이미지에서 다양한 패치를 확보함 |
| 밝기·대비·감마 증강 | 이미지 간 조명 편차에 강건하도록 함 |
| 회전·뒤집기·약한 확대축소 | 미세조직은 방향성이 없어서 기하 증강이 자연스러움 |
| CrossEntropy + Dice 손실 | 소수 클래스(Si 상)가 다수 클래스(Al)에 묻히지 않도록 함 |
| 전체 이미지 추론 + 뒤집기 TTA | 패치 경계 문제 없이 예측하고, TTA로 앙상블 효과를 얻음 |
| 로컬(MPS)에서 코드 검증 → Colab T4에서 학습 | 노트북으로 짧게 돌려 오류를 먼저 잡고, 본 학습은 무료 GPU로 돌려서 노트북 작업과 병행함 |
